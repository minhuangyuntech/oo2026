Companion project for slides 1–88 of [Django Website Case Studies](https://minhuangyuntech.github.io/oo2026/django-case/).

Includes the complete Django project, initial migration, admin, five sample posts, templates, local Bootstrap assets, Markdown sanitizer, and tests. The blog interface and sample posts use Traditional Chinese, matching the original example. The three guides explain the same shared project. No AI service, API key, existing database, or preset administrator account is required.
